## 🍔 Aplicación para emprendedores de comida

Proyecto en etapa de planificación.

La aplicación estará orientada a personas que elaboran y venden comida desde sus hogares.

### Objetivos principales

- Facilitar la venta de comida casera.
- Permitir administrar el stock disponible.
- Permitir pedidos para retirar o recibir mediante envío.
- Ofrecer promociones para vender excedentes del día.
- Ayudar a reducir el desperdicio de alimentos.
