# 🍔 App de comida para emprendedores

## 📌 Descripción

Aplicación orientada a pequeños emprendedores que elaboran y venden comida desde sus hogares.

El objetivo es ofrecer una plataforma sencilla donde puedan publicar sus comidas, administrar el stock, recibir pedidos y ofrecer promociones para aprovechar los productos que necesitan vender durante el día.

La aplicación también busca ayudar a reducir el desperdicio de alimentos.

---

# 🎯 Objetivos del proyecto

- Ayudar a pequeños emprendedores a vender sus productos.
- Permitir controlar fácilmente el stock.
- Facilitar los pedidos de los clientes.
- Ofrecer opciones de retiro y envío.
- Crear promociones para vender excedentes.
- Reducir el desperdicio de comida.
- Ofrecer una alternativa con costos accesibles para los emprendedores.

# 📦 Sistema de stock

Cada emprendedor podrá indicar cuántas unidades tiene disponibles.

Ejemplo:

Producto:

🍔 Hamburguesa casera

Stock:

10 unidades

Si vende 3:

Stock disponible:

7 unidades

Cuando el stock llegue a 0:

**Producto agotado**

El producto ya no debería poder ser comprado.

---

# 🔥 Sistema de promociones

Una de las funciones principales de la aplicación será permitir que los emprendedores creen promociones para vender productos que necesitan salir durante el día.

## Ejemplo

Un emprendedor prepara:

20 empanadas.

Durante el día vende:

15 empanadas.

Le quedan:

5 empanadas.

El emprendedor puede crear una promoción:

🔥 PROMOCIÓN

Empanadas x5

Precio normal: $10.000

Precio promoción: $7.000

Disponible hasta: 21:00

Cantidad disponible: 5

Esto permite que:

👨‍🍳 El emprendedor recupere parte de su inversión.

👤 El cliente consiga comida a un precio menor.

♻️ Se reduzca el desperdicio de alimentos.

# 🛒 Sistema de pedidos

El cliente podrá seleccionar un producto y realizar un pedido.

El pedido deberá contener:

- Cliente.
- Emprendedor.
- Productos.
- Cantidades.
- Precio.
- Total.
- Método de entrega.
- Estado del pedido.

---

# 🚶 Retiro

El emprendedor podrá indicar que permite retirar el pedido.

El cliente recibirá la información necesaria para realizar el retiro.

---

# 🛵 Envíos

El emprendedor podrá ofrecer envío.

La aplicación deberá permitir establecer:

- Zona de entrega.
- Costo de envío.
- Tiempo estimado.
- Estado del envío.

En una etapa posterior podremos analizar diferentes alternativas para calcular el costo de envío.
